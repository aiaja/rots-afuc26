# rots-afuc26

Aplikasi iOS RotsAfuc26 — integrasi 3D Canvas (RealityKit & Spline) dan SwiftData untuk iOS 18+ / macOS 14+.

## Persyaratan
- Xcode 16+ / Swift 5.9+
- iOS 18.0+ / macOS 14.0+

## Struktur Project
- `Package.swift`: Swift Package Manager manifest dengan dependensi Spline iOS
- `RotsAfuc26/`: Source code utama (App, Core, Features, Previews, Resources)
- `RotsAfuc26.xcodeproj`: Project Xcode
